# GabaritAI

Sistema inteligente para correção automática de cartões-resposta utilizando Visão Computacional.

## Objetivo

Automatizar a correção de provas objetivas através da comparação entre um gabarito oficial e os cartões-resposta dos alunos utilizando OpenCV.

## Tecnologias

- Python
- FastAPI
- OpenCV
- MySQL
- HTML5
- CSS3
- Bootstrap
- JavaScript
- Chart.js

## Funcionalidades do MVP

- Login
- Cadastro do gabarito
- Correção automática
- Ranking
- Dashboard
